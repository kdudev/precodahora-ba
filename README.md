# precodahora-ba
Biblioteca que fornece uma interface simples e programática para buscar produtos, consultar sugestões e aplicar filtros como localização, faixa de preço e categorias, facilitando o uso dos dados em aplicações, estudos de mercado, pesquisas de preços e análises para compras públicas unicamente da plataforma "Preço da Hora" do Governo da Bahia.
